Android抓包小白教程

发表于2026-07-23|更新于2026-07-22
|浏览量:

今天给大家说一下安卓设备怎么抓包，安卓抓包比小程序抓包稍微麻烦一些，而且根据不同的安卓版本，抓包方式也不一样

基础工具安装

不管怎么样，你抓包总得有工具吧，总不可能随便那个夹子就能“抓”，工具链接我放这了，大家自取

解压后就跟安装普通软件一样，没什么区别，安装好了之后点那个模拟器助手，然后点多开助手里面的添加模拟器，添加个安卓5的设备，接着启动，你可能会看到如下的报错，看到这个你就直接点关闭就行，关闭之后重启一下电脑就ok啦

其实不是必须要用这个夜神模拟器，只不过是夜神模拟器是市面上我能找到唯一能用安卓5的模拟器了，你用其他模拟器也差不多的。

安卓5以下抓包很简单 低版本安卓系统对证书校验较宽松，只需安装用户证书即可。所以我这就直接跳过安卓5及其以下版本的抓包了，直接上安卓5及其以上版本的。

下载并安装Burp Suite证书

这里有俩方法，一种是直接在BP里面下载（就是当时我们配置BP的时候一样的方法导出即可，那篇链接我放在这了[Burp Suite V2026.4.3安装 | Sonh’s Blog](https://sonh66.github.io/2026/07/21/Burp Suite V2026.4.3安装/)）

还有一种是在浏览器配置代理然后在里面搞

先打开BP把你的网络代理上，顺便把浏览器里面的BP代理也打开

接着在浏览器中打开

点击上面的CA Certificate

然后你会下载到一个.der文件 在下面的网址里面把搞个的der证书转换格式

记得把输入和输出格式选择一下

然后用 OpenSSL 计算证书的哈希值并改名

计算出来后改文件名为9a5ba575.0

确保mumu模拟器里面的设置都是这个

打开mumu模拟器的共享文件夹，把你刚刚的证书放进去

用adb查看一下你的模拟机端口号

可以确定就是127.0.0.1:7555了，那接下来就直接用adb命令导入安装证书吧

模拟器重启后，执行以下命令，看看证书是否安装成功

如果能看到 9a5ba575.0，说明证书已经成功装入系统证书区。

配置代理

先ipconfig一番你的ip，找到你的WIFI网卡，看看上面写着什么

然后回去mumu里面的手机WiFi把地址改成手动的

接着回去我们的BP配置一下

最后验证

  1. 确保 Burp 正在运行，Intercept 处于 off 状态（自动放行）
  2. 在模拟器浏览器访问 https://www.baidu.com
  3. 回到 Burp → Proxy → HTTP history，应该能看到请求记录
  4. 如果连不上，大概率是模拟器与电脑不在同一网段，需要开启 MuMu 的网络桥接模式：
  5. MuMu 设置中心 → 网络 → 勾选 开启网络桥接模式
  6. 网卡选择你当前用的 Wi-Fi 网卡
  7. 保存并重启模拟器
