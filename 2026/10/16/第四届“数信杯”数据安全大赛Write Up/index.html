几个关键观察：

  1. 服务无交互：打印完 banner 后直接关闭连接，因此这是一道纯粹的离线数学题，不能”喂数据”探测。

  2. 参数每次全新：多次连接得到的 p、h、flag_enc 都不相同。p 是随机生成的 256 位素数。

  3. 长度关系：n = 1024，h 恰好 1024 项；flag_enc 为 76 个 hex 字符 = 38 字节，说明它是由某个与权重相关的密钥流异或得到的（flag 长度 >= 38）。

据此可以确定解题链条：*公开数据 h → 反演出真实权重 w → 用 w 的哈希派生密钥 → 解密 flag_enc。*

这就是莫比乌斯反演思想在这个特殊加权下的具体形式。实现时先预处理每个数的约数表，整体复杂度 O(n log n)，n = 1024 瞬间完成。

“使用所有权重的哈希值加密了 Flag”，还原出的权重向量按如下方式生成密钥流：

  1. 把每个权重 w[i] 编码为 32 字节大端整数（权重均小于 256 位素数 p，正好装得下）；

  2. 拼接后求 SHA256，得到 32 字节摘要作为 key；

  3. 将 key 循环填充到 flag_enc 的长度（38 字节）得到密钥流 ks；

  4. 逐字节异或解密：flag = flag_enc XOR ks。

题目只给了”加权狄利克雷卷积”这句话，既没有源码也没有精确定义，理论上存在大量候选（权重因子取 d 还是 n/d、卷积核是 1 / mu / phi / sigma、哈希怎么编码……）。这里用一个很漂亮的技巧把不确定性彻底消掉：
